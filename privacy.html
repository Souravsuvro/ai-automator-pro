Privacy Policy

Last updated: 18 September 2026 · Aligned with Wix App Market privacy expectations and GDPR principles.

Who we are

AI Automator Pro is a SaaS tool for Wix site owners and partners. It generates marketing, SEO, and automation guidance from a Business DNA profile you provide.

Data we process

  • Business DNA profile — stored in browser localStorage by default.
  • Usage counters — free-tier limits in localStorage.
  • Optional Wix instance id — when loaded in a Wix dashboard iframe via the instance query parameter.
  • Generation requests — sent to the API only to produce output when a server LLM key is configured.

Your controls

  • Clear all local data from in-app Docs.
  • Request deletion of server-side records via the operator contact.
